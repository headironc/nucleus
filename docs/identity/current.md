# 当前身份与本人账户读取

本文拥有普通业务入口的会话证明、可信操作者、当前账户资格复查，以及本人账户的一致投影。会话创建与原登录结果归各认证入口；逐会话撤销见[会话撤销与退出](revocation.md)，账户暂停见[账户暂停与恢复](suspension.md)，注销见[账户注销](cancellation.md)，微信关联依赖见[微信身份登录](wechat.md)。

## 身份边界

正式账户固定关联一名人员。登录只证明本次请求可使用该账户，不授予领域参与或管理权限。各业务所有者仍按当前领域授权、角色、目标和动作独立判断。原注册回执、待注册凭据、登录结果交接和已清理的协议记录均不是长期会话证明。

根 HTTP 对要求登录的普通路由先解析明确选中的会话凭据，并检查适用同源条件。Identity 核对原会话、账户和来源后，才产生本次请求的受控 Actor。Actor 只固定原账户 ID、Session ID 和可信应用来源；不携带 token、实名、领域权限或可跨请求复用的有效状态。客户端不能提交 Actor、账户 ID、应用身份或认证方法来改变操作者。普通业务写入仍在适用对象协调之后，以 Actor 固定的原会话和账户重新读取当前资格。

网站认证只读取选定 Session 的 cookie，并检查同源条件。小程序在本人账户、当前退出、全部退出和原退出读取使用 Bearer；其他现有网站入口保持网站凭据范围。下游不重复读取凭据。

## 凭据选择与来源

网站会话以必需的 `Session-Id` 头选定会话 ID，按[项目标识](../identifiers.md)解析 UUID 值，不强制输入规范文本。服务端用该值的小写、带连字符形式定位对应名称的受保护 cookie。同值的不同 UUID 文本选择同一 cookie；不直接拼接原始头值。cookie 保存服务端随机会话 token；ID 本身不构成登录证明。目标 cookie 缺失时不搜索其他有效 cookie，也不选择最近登录。重复目标 cookie 拒绝；其他会话 cookie 与微信授权流程 cookie 不参与本次选择。Cookie 读取、设置和删除共用同一名称规则，迟到响应仍只影响原 Session。

支持小程序的入口接收唯一的 `Authorization: Bearer {token}`，token 是规范编码的 32 字节随机秘密。重复头、空值、非法格式，以及同时携带 `Session-Id` 或会话 cookie 都返回 `400 invalid_input`，不回退到其他凭据。Bearer 不要求网站 Origin，缺少 Origin 也不会选择 Bearer。其他网站入口继续拒绝 Authorization。

网站模式继续拒绝重复、空值、多值或非法的 `Session-Id`；缺少选择或目标 cookie 返回 `401 authentication_invalid`。合法小程序 token 通过网站 cookie 呈递同样返回 401，保持共同接纳。匿名入口不会因附带凭据而进入当前会话认证。

会话保存创建时固定的实际 AppID 和认证方法。Cookie 按选定 Session ID 定位，Bearer 按唯一 token 摘要定位；随后核对 token、配置来源、账户与期限。来源只允许网站短信或小程序手机号，传递方式从来源派生。未知 AppID 或非法方法组合是持久事实错误，拒绝开放相关入口。短期认证及交接合法清理后，仍依据 Session 自身来源认证。

网站 cookie 模式的非安全方法要求唯一、准确匹配固定 HTTPS origin 的 `Origin`。GET 没有 `Origin` 时仅接受 `Sec-Fetch-Site: same-origin`；有 `Origin` 时它必须准确匹配，若同时有 `Sec-Fetch-Site`，其值也必须为 `same-origin`。`null`、重复、多值、同站子域和跨来源均拒绝，不用 `Referer`、`Host` 或转发头补足。缺少 Origin 不会选择另一种认证来源。普通请求的 Operation-Id 不作为会话证明，也不创建读操作的原请求记录；响应关联使用[客户端保存的请求上下文](../client/protocol.md#响应可信性)。

Origin 限制用于阻止浏览器自动携带 cookie 发起跨来源用权，不代替[不透明会话 token](session.md#来源与秘密) 或业务授权。网站 cookie 的 HttpOnly、Secure、SameSite 和范围见[网站持久会话](website.md)。

网站凭据不开放跨 origin CORS。网站使用专属受信主机；同一主机的其他端口也不得承载互不信任的服务，因为 cookie 不按端口隔离。静态资源、签名图片、健康、OpenAPI、微信回调和匿名结果读取各守原入口证明，不因浏览器附带登录 cookie 而取得本人身份。

## 当前会话资格

一次会话验证在同一决定性快照内读取原 Session、Account、可信时间、撤销事实及适用的当前微信关联。须同时满足：原 token 匹配；会话的账户与来源关系有效；尚无撤销；可信时间严格早于原到期时刻；账户存在且未暂停。微信身份会话还须引用同账户当前绑定的原修订。手机号会话不依赖微信绑定。解绑后重绑即使身份相同，也不能使旧微信会话复活。

Session 的账户、token 摘要、应用来源和方法建立后不可改。删除原绑定时，已撤销会话的关联可以清空，但不能改挂。已撤销的微信会话无论保留原关联还是关联已清空，都不能通过当前认证。未撤销的微信会话必须保持原绑定关联，其他方法不拥有绑定关联。会话事实存在不能单独构造 Actor。

Actor 产生后，具体用例须按自己的决定性时点复查。本人读取重新验证原会话；写入用例在对象协调后重新检查原会话、账户及适用业务条件。不得换成同账户另一会话、后来浏览器选择或新绑定。原证明通过不冻结期限、撤销、暂停或绑定状态。其他请求已确认的到期不能因时间回拨而复活。单笔提交未知不暂停无关办理；当前身份验证与本人资料读取在可靠快照中继续，读取失败不代替原写入结局核对。

认证及本人资料读取发现必要持久事实损坏时，关闭共同接纳。包括必要关系缺失、非法会话来源、撤销归属矛盾、摘要错误，以及实名材料损坏。原 Session 不存在是普通失效；Session 仍在却缺少所引用的 Account 是关系损坏。正常注销先移除会话再移除账户，不能用孤立会话模拟合法注销。普通查询失败不据此关闭接纳。修复存储不自动重开接纳，重新启动时仍须通过完整核验。

两种网站退出和原退出读取复用同一资格确认。撤销归属与会话账户矛盾是持久事实错误，不作为失效会话处理。Actor 始终固定原 Session，决定性读取不能换成同账户的另一会话。

[本人机构角色读取](../access/roles.md#原请求与读取)、[本人当前政治面貌](../center/affiliation.md#目标确认与读取)、[本人更正历史](correction.md#历史读取)、[换号状态](mobile.md#原请求读取与会话)、[已知账户头像](avatar.md#已知账户读取)及 [Workforce 本人读取与领域准入](../access/grants.md#授权建立与当前状态)复用同一身份与时间确认。各消费者在同一快照取得当前账户所属人员、当前实名版本及决定性时刻；领域准入使用同一快照的实名版本固定办理人。管理资格、业务资料加载与永久事实鉴别由各消费者拥有，身份确认后才解释和交付业务资料。

机构更换先协调涉及的两个账户，再复查原 Session 与当前资格。Identity 只拥有身份事实；Access 继续拥有指派权、角色、目标等级及原操作判断。

## 本人账户投影

当前头像的核对和链接投影由 [Avatar](avatar.md#已知账户读取) 拥有。本人资料与已知账户读取共用这些规则；必要头像损坏返回技术失败并关闭共同接纳。

`GET /api/v1/accounts/current` 只读取本次 Actor 固定的本人账户，不接受目标账户参数。决定性快照共同复查 Session、Account、Person、当前实名版本、当前头像、当前微信绑定和可信时间。必要实名版本必须属于该人员；头像须是同一账户的当前头像。读取区分真实未绑定、失效会话与必要资料损坏，不把任一失败填成空绑定或默认资料；必要资料缺失或归属不符时报告技术失败，不能当作查无会话。

通过当前认证与关系检查后，服务端解密当前姓名和身份证号，只投影完整姓名及身份证号最后四个字符。`idNumber` 为 `{ suffix: string }`，保留前导零，不返回完整号码。响应的 `account` 包含 `id`、`personId`、`revisionId`、`name`、`idNumber`、当前 `avatar` 和必有的 `binding`。真实未绑定时 `binding` 为 `null`；已绑定时仅含当前 `revision`，不输出 UnionID、OpenID 或供应商材料。头像链接在取得完整有权快照后按其所属签名协议生成，不从另一快照拼接旧实名或新头像，也不读取图片正文。

成功返回 HTTP 200、`code: ok` 与完整 `account`，并设置 `no-store`，不回显请求标识。该 GET 不写 Identity 事实、不签发或刷新会话 cookie、不延长期限，也不按 Operation-Id 返回旧资料。重复读取反映各次可靠快照；资料在决定性快照之后变化时，已完成的响应可代表读取时点，后续用权仍复查。客户端仅在原 Session ID 与本地选择修订仍匹配时接纳迟到响应，不能把旧账户资料写入后来选择的账户页面。

## 拒绝与验收

| 情形                                                                                  | HTTP 与 code                 | 边界                                                 |
| ------------------------------------------------------------------------------------- | ---------------------------- | ---------------------------------------------------- |
| 凭据混用、头或 token 结构错误、重复头或重复目标 cookie                                | 400 `invalid_input`          | 拒绝本次请求，不改会话或回退到其他凭据。             |
| 网站同源条件不成立                                                                    | 403 `permission_denied`      | 不读取本人资料或执行业务。                           |
| 缺少认证选择或目标 cookie、秘密错误、来源不符、到期、撤销、账户不可用、原微信关联失效 | 401 `authentication_invalid` | 不泄露是哪项失败，也不判断此前写入是否成功。         |
| 数据库或可信时钟不可用、存储来源异常、必要关系损坏、解密或头像签名失败                | 503 `dependency_unavailable` | 不返回部分资料，不伪造成退出、正常未绑定或默认头像。 |

网络错误或 503 不证明会话已失效；客户端保留原会话选择，重试时重新核验。普通当前读取不返回 `outcome_unknown`、进度或原写入完成。

验收以可控交错覆盖认证通过后的到期、撤销、暂停、解绑和注销，以及实名、头像、绑定变动前后的整份快照。另须验证两端来源错配、同值 UUID、重复及畸形 cookie、Authorization 拒绝、同源负例和持久来源损坏。短期认证记录清理后，有效会话仍能使用。当前读取不产生业务写入，错误不伪装成空资料，迟到响应不能覆盖新会话选择。每项持久损坏使共同接纳关闭，错误 token、未知会话及正常到期保持接纳；普通查询故障恢复后，原会话可重新认证。时间验收覆盖等待期间到期与决定性时间回拨。图片 IO、许可与缓存验收归[头像](avatar.md#验收)。
