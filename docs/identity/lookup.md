# Identity 号码查找摘要目标设计

本文拥有手机号与身份证号的查找用途；值规则归[匿名身份 HTTP](../http/identity.md#请求字段) 和[正式注册](registration.md#业务边界与不变量)，摘要编码与密钥协议归[密钥材料](../keys.md)。

## 编码与用途

手机号和身份证号的确定性查找摘要都使用 `lookup` 派生用途，以各自冻结的域互相隔离。摘要只由受控规范号码、所属域与活动根的 `lookup` 键决定，不加入账户、人员、版本、原操作或随机值；同一用途下，相同规范号码形成相同摘要。查找摘要不用于还原原号码。

当前账户、待注册凭据、认证挑战与注册尝试中保留的手机号采用同一规则；消息及校验沿原挑战读取，不另存手机号占用值。账户的身份证号摘要只代表同一人员当前实名版本的占用，历史版本不单独占用号码。计算或读取失败是错误，不能折叠成“没有占用”。

## 密钥版本与核验

号码查找值不按行记录密钥版本，也不在运行请求时按多个密钥版本查找。更换查找键的停写、重算、事务结局及材料切换见[密钥维护](../operations/keys.md)。

启动和维护核验使用与业务写入相同的编码。保存摘要与规范明文不符是完整性故障，不能折叠为没有占用。原请求输入和微信 code 的密钥版本规则不随查找键轮换改变。

## 验收

使用独立固定向量验证两种用途、规范值等价、用途隔离和完整结果，期望值不得由被测实现生成。验证不同账户的相同规范号码得到相同查找值，当前身份证号更正后旧版本不再占用，暂停账户仍占用。换钥故障与材料核对按[密钥维护](../operations/keys.md)验证。
