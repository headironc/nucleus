# 账户头像

本文拥有账户头像的默认内容、更换、读取、链接与清理边界，共同恢复规则见[架构恢复协议](../architecture.md#原操作与恢复)。

## 业务边界

每个正式账户在创建事务提交时已有可用头像。用户凭当前有效会话维护自己的头像；更换失败保留原头像。头像变化不改变人员身份、实名、政治面貌、微信绑定、领域授权或工牌照片，也不触发工牌换证。头像链接的签发面向已登录用户，不附加领域权限。已签发的有效链接可转发并匿名读取；退出、失权或更换头像不立即撤销链接或已取得的图片字节。链接路径随 HTTP 版本前缀固定为 `/api/v1/avatars/…`；迁移前的根路径 `/avatars/…` 不保留别名，该迁移发生在首次部署之前，没有已签发的旧链接需要过渡。以后改变签名链接路径的版本迁移须为未到期链接保留过渡入口，至少覆盖最长签名寿命。

默认内容由应用随版本发布的十张冻结静态无损 WebP 和清单提供。清单固定序号、摘要、大小与尺寸；启动核对实际字节，缺失或不符时不能提供依赖头像的服务。注册及合法初始建户按可信规范手机号末位选择默认图，在同一账户创建事务保存独立头像行和初始头像修订；默认图不复制到私人头像目录。默认素材本身不进入清理。个人上传的结果若恰与默认图字节相同，也只保存新头像行，不发布文件。相同内容不跨账户共用头像行。

头像内容不可改，释放不可逆；一个存在的账户恰有一个当前头像。

## 入口、输入与结果

| 入口                                  | 资格与结果                                                                                                                                 |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `PUT /api/v1/accounts/current/avatar` | 当前本人会话、Operation-Id、Avatar-Revision、Content-Type 与原始图片正文；成功返回 200、原 `completion` 与当前 `avatar`。                  |
| `GET /api/v1/replacements/{id}`       | 当前本人会话，路径 ID 为原更换的 Operation-Id；同账户跨端只读原完成与当前头像，不要求图片正文。无可读完成时返回 404 `result_unavailable`。 |
| `GET /api/v1/accounts/{id}/avatar`    | 当前有效会话读取已知账户的当前头像；不开放账户目录，未知或已注销账户统一返回 404 `target_unavailable`。                                    |
| `GET /api/v1/avatars/{digest}.webp`   | 持有效签名读取静态无损 WebP；不要求会话或普通 Operation-Id。                                                                               |

网站使用准确选中的 cookie、Session-Id 及同源条件，小程序使用 Bearer。头像更换和两个 JSON 读取始终重新核对当前会话及账户资格。客户端不能在请求中另指定更换目标。`Avatar-Revision` 是独立的 UUID 期望修订；绑定修订、实名版本及账户身份不替代它。实际更换生成新头像修订，“无需变更”保留原值。JSON 结果均禁止缓存。

PUT 与原请求匹配时，固定所属账户、原 Operation-Id、期望修订、媒体类型和原上传字节的 SHA-256 摘要。摘要只识别同一次上传，不能用处理后摘要替代。原成功先于当前修订判断；输入不符返回 409 `request_mismatch`。已匹配原成功直接读取原完成和当前头像，不重新解码、编码或发布。新操作须使用新 Operation-Id。GET 请求头中的 Operation-Id 只标识本次查询，路径 ID 才是原更换标识，响应不回显本次请求标识。查无完成不证明原事务回滚，也不触发新上传。已知原提交仍待核对时返回 503 `outcome_unknown`；普通数据库或签名依赖失败返回 503 `dependency_unavailable`，不能伪造成 404。

成功 `completion: { id, changed, revision, completedAt }` 描述原办理，`id` 为原 Operation-Id。`avatar: { revision, href, expiresAt, mediaType, width, height }` 描述本次决定性读取时的当前头像；两种修订可以不同。两者在同一数据库语句快照中取得，签名链接按实际签发时刻生成。签名失败只使响应失败，不撤销已提交的更换；客户端保留原操作定位，随后用完成 GET 核对。

### 已知账户读取

`GET /api/v1/accounts/{id}/avatar` 及 HEAD 供网站读取已知账户的当前头像。路径按账户 UUID 解析，入口复用[当前身份](current.md)的 Session 选择和读取同源条件。只要求请求者的会话及账户有效，不要求机构权限或目标等级。本人、其他账户和暂停目标均可读取；已注销目标与未知账户统一返回 404。接口只披露头像，不附带人员、实名或管理资料。

GET 不接收查询参数或正文，沿元数据预算。成功返回 200、`code: ok` 和六字段 `avatar`，使用 `no-store`，不设置 cookie。HEAD 保留状态和头，无正文。无效请求者返回 401 `authentication_invalid`；数据库、元数据或签名失败返回 503 `dependency_unavailable`。普通读取不建立原结果，也不返回 `outcome_unknown`。HTTP 等待最多 30 秒。

请求者资格与目标当前头像在同一[只读快照](../http/lists.md)中确认，链接按快照后的可信时间签发。资格判断后的退出不改变既有快照，下一次读取重新检查。

本人投影与已知账户读取共用头像核对与 `avatar.Current` 响应形状。目标存在而必要头像缺失是损坏，不能过滤成 404。默认内容按冻结清单核对。私人内容除尺寸与大小边界外，还须验证内容证明。证明绑定头像 ID、所属账户、修订、摘要、大小和尺寸，由已核验发布意图的采用事务建立，随头像保留。没有证明的内容必须匹配冻结清单；未知摘要不能自行证明它是上传内容。违反这些事实时返回技术错误并关闭共同接纳。普通查询失败仍保留技术原因，不等同于损坏。

## 上传处理与事实

仅接受 Content-Type 与实际格式一致的静态 PNG、JPEG 或 WebP 原始字节；不接受 multipart、远程 URL、动画或客户端路径。输入最多 2 MiB，宽高相同且在 1 至 1024 像素内。超量返回 413 `avatar_too_large`，不支持或声明不符的格式返回 415 `avatar_format_unsupported`，损坏、动画或尺寸不合规则返回 400 `invalid_input`。完整解码后转为 RGBA8，再编码成静态无损 WebP，不复制输入元数据、不隐式裁剪、缩放或按 EXIF 旋转。输出写入时限制为 8 MiB。无损以处理后的 RGBA8 为基准；编码器升级可能改变输出字节，因此新操作以实际输出字节比较当前头像，原操作重放不重新编码。资源峰值与耗时须在实施时测量。

每个头像有独立 ID、所属账户、内容 SHA-256、大小、正方形尺寸及可为空的释放时刻。当前头像尚未释放；一个存在的账户恰有一个当前头像。释放的头像不再成为当前，不能改回或复用 ID。非默认内容按头像 ID 定位私人文件，内容不可改；默认内容由清单定位。账户删除后释放的头像仍可按宽限清理。

原更换完成以原 Operation-Id 标识，记录原账户、期望修订、媒体类型、原上传摘要、本次结果修订和完成时刻。两修订相等表示“无需变更”，不同表示实际更换。原完成不依赖可清理的旧头像，不保存上传正文或处理后文件。它随账户保留，只在账户注销时删除。滚动一小时成功更换次数只计实际更换的已提交完成；默认每账户最多 10 次。失败、无需变更和重放不计。完成、头像与账户修订共同成立。

账户的永久推进历史保留实际更换事实，并验证前后头像修订的连续关系。该历史不依赖可清理头像或随注销删除的可查询原完成。注销后仍可核验既有账户推进，不能据可查询原完成缺席否认已确认的提交。

## 工作、事务与故障恢复

上传接纳起的 HTTP 总等待预算为 30 秒，含认证与原完成检查。正文接收最多 15 秒，解码等待最多 5 秒，进入业务写入后的等待最多 10 秒，均受总剩余时间约束。上传及处理共用两个许可，认证后且读取正文前取得；许可随原受监督工作持有至实际处理结束，HTTP 断连或超时不能提前释放。图片传输另用八个许可和 30 秒上限。无许可拒绝而不建立无界队列。完成 GET 不占上传处理许可；限流与实际峰值按独立图片预算验证。慢文件操作不能阻塞 HTTP 超时处理；停止排空仍等待实际文件工作结束。

新上传先有界读取原字节并计算摘要，在事务外完成解码和编码。实际更换先核对滚动小时额度；额度已满时不创建发布意图或私人候选。所属 SQL 发布意图固定原操作、原账户、期望头像修订、原上传身份和候选 Avatar ID。确认意图提交后才创建持久候选，按[文件发布协议](../architecture.md#发布与接纳)完成同步和不覆盖发布。恢复未完成意图时，先重查当前修订和适用额度，再处理候选文件。候选尚不属于可读 Avatar；同操作的唯一工作负责它，查无 Replacement 不授权第二次处理。

工作在事务外读取并比较当前头像的实际字节，固定所读头像 ID 与修订。结果事务按共同顺序协调原操作、Account 和资源，锁后重查当前认证、原完成、期望修订及数据库时间。当前头像身份变化时回滚并重新判断；期望修订变化返回 409 `avatar_changed`。摘要相同而字节不同是完整性故障，不能作为无需变更。

字节相同只插入“无需变更”的 Replacement，当前头像、修订和次数均不变。字节不同时，结果事务再次核对滚动小时额度，防止并发更换超额。随后共同释放旧当前行、插入候选 ID 的新 Avatar、推进头像修订、保存 Replacement 和意图采用结果。非默认文件在事务前已经持久发布，默认内容不用私人文件。事务失败保留原头像，候选按所属意图收尾。

提交未知时按[原操作恢复](../architecture.md#未知提交)核对 Replacement 和意图采用关系。后来的头像变更或合法清理不否认原完成。确认未提交后，仍按原会话、输入及当前资格决定后续；候选清理必须等待旧执行结束。

释放的头像默认保留 24 小时，期限由[头像保留设置](../settings.md#4-可调项)配置。替换或注销释放的头像可在可信时间到达宽限等号时清理。清理核对准确释放来源，并确认原工作结束。替换记录的原头像修订必须与待清理头像一致，不能移用同账户另一笔真实替换的操作和时刻。默认内容仍须符合冻结清单；私人内容须与保留元数据一致。当前头像始终保留；在途工作使本次清理跳过，后续再次处理。

默认头像删除结果未知时，按[原操作恢复](../architecture.md#未知提交)核对准确对象，不能把暂时缺席当成原注销失败。回读失败保留未知结果；损坏事实关闭共同接纳。默认素材永不删除，原注销完成与签名默认图读取均不依赖已释放头像。停止和排空保留已开始清理的结果核对责任。

私人头像在真实引用和原工作结束后，按[删除协议](../architecture.md#删除与读取)清理。删除意图与头像移除共同成立，确认后才删除私人文件；启动恢复未完成的文件后果。删除未知时核对原删除意图，不凭头像缺席推断原业务失败。已打开读取可完成，合法清理后的私人图旧链接返回 404。仍有保留事实而文件缺失或损坏时，拒绝启动或关闭共同接纳，不能视作合法清理。

在线与维护启动共同核验保留的上传完成、发布意图、删除意图及原完成的配对关系。维护入口通过这些数据库核验后才开放命令，不依赖 HTTP 或私人文件服务。在线启动另核对私人文件字节，并恢复未完成的文件后果。

## 链接与缓存

JSON 入口只给当前有资格的请求者签发链接。头像投影使用实际保存 WebP 内容的 32 字节 SHA-256；路径只接受恰 64 个小写 ASCII 十六进制字符。签名查询只接受规范且各出现一次的 `key_id`、整数 Unix 秒 `expires_at` 和无填充 base64url `signature`。签名使用 `link` 派生用途及头像链接专属的域，绑定根版本、内容摘要和到期秒；字节编码与恒定时间校验由独立向量固定，不能由通用序列化格式自行决定签名字节。

链接从实际签发时刻起默认 24 小时有效，`now >= expires_at` 时拒绝。旧签名键停止签发并排空后，至少保留到最后可能签发时刻加允许的最长期限；可信时间尚未到达时不得退役。校验失败在访问存储前返回 403 `avatar_link_invalid`。签名通过后，默认摘要从冻结素材读取；其余摘要在头像行中找实际所有者并打开对应文件。合法清理后无可读行返回 404；应存在的文件缺失或元数据矛盾返回技术错误，不伪造正常清理。图片成功直接返回 `image/webp` 字节，设置 `nosniff` 和不超过剩余签名期限的私有不可变缓存；错误 JSON 不缓存。传输开始后故障只中断字节流，不追加 JSON。

当前头像选择只能从最新有权 JSON 投影取得，图片缓存不证明当前身份或一次更换完成。当前修订未变且原链接有效时客户端复用原链接；修订变化时接纳新投影。图片链接到期或旧内容已清理时，客户端重新取得链接并至多重试一次，不自动重新上传。日志和代理访问记录不保存完整签名 URL、上传正文或原请求摘要。

未签名、错键和异字段证明不能探查内容；有效证明指向未知摘要返回 404。查询参数拒绝非规范数字与签名编码，以及缺失、重复或未知字段；实际有效期由验签后的可信时间判断。

图片读取共用八个传输许可，从取得许可起共用 30 秒截止，覆盖处理、正文和实际传输；许可持有到真实连接结束，handler 返回或正文被复制不释放许可。每个图片响应，包括失败和 HEAD，都设置 `Connection: close`。停止时拒绝新的图片读取；已登记请求先完成有界读取，再中断图片连接的传输。成功缓存扣除已经过的处理时间，错误仍为 `no-store`。

## 验收

默认头像清理验证自助和管理注销、宽限前保留、等号到期、当前头像保护、分批遍历及在途工作跳过后重访。清理后原注销恢复、签名默认图读取及重启保持可用。失败验收覆盖回滚、延迟提交、独立回读失败和排空，核对准确对象与原工作结束。

把同账户旧替换的真实操作和时刻移到另一张已释放头像时，清理拒绝并关闭接纳，保留元数据和文件且不创建删除意图。维护启动接受有效的保留上传事实，发现上传证明损坏时拒绝开放命令。

已知账户读取验证普通账户可读取管理者和暂停目标、自身原会话失效后拒绝、读取不改变头像与会话事实、注销释放原头像，以及六字段投影、准确冻结 WebP、HEAD、无缓存、来源、输入、缺席和查询失败诊断。缺失头像、异常尺寸、摘要及大小使本人投影与已知账户读取都失败并关闭共同接纳；普通查询故障恢复后可继续读取。链接验证规范参数、等号到期、保留旧键、缓存头，以及八个许可、第九个拒绝、连接持有、30 秒截止和 HTTP 排空。

用真实事务及可控文件故障验证：新账户恰有一张默认头像；实际更换、无需变更与失败分别对当前行、修订和额度的影响；原上传与原头字段匹配、异输入拒绝及编码器升级后的重放；并发同修订更换、上传期间退出和原会话失效；发布后回滚、提交未知、旧驱动晚提交及普通重启后的按需核对；删除行提交未知、文件删除中断及读取与清理竞争；默认内容不发布私人文件；原完成与后来当前头像分离；提交后签名失败仍可查询原完成；跨账户结果不可读。另以固定字节向量验证签名编码、摘要规范、到期边界和旧键保留，以真实图片样例验证静态格式、透明像素、元数据剥离及资源预算。
