# 首页编排目标设计

状态：暂缓实施的后续设计参考，不属于当前内部工牌交付范围。恢复本能力前按[简化架构](../architecture.md)重新核对需求和技术方案；以下旧目标不要求当前功能建立封印、版本链、后台恢复或其他前置设施。

本文拥有首页编排的区块类型、链接目标、发布校验、公开解析和上线前后的站点衔接。草稿、版本、上线事件及其并发与恢复由[共同协议](publication.md)拥有，入口与错误码见[内容 HTTP](http.md)。

## 业务边界

首页由有序区块组成，在网站管理页编辑。首页编排是唯一的内容对象：全部区块作为一个整体版本一起保存、预览和发布，不按区块分别上线。区块参考[公开首页稿](../../design/halo-home.html)的轮播主视觉、栏目入口和文章列表，以及参考图中的轮播与推荐位。页头、导航、员工服务入口和页脚属于站点固定外壳，不由编排维护。

在本能力交付之前，首页内容随网站发布写死。交付后站点服务端读取已上线的首页编排；首次发布前，公开读取返回 `404 home_unpublished`，站点继续使用随网站发布的内置首页。

## 区块类型

区块类型、字段和数量是带格式版本号的封闭集合，未知类型或字段拒绝。草稿至多 12 个区块，允许为空；发布要求至少 1 个区块，否则返回 `409 home_incomplete`。同一类型可以出现多次。

| 类型       | 内容                                                                                                                                                                                   |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `carousel` | 1 至 8 张轮播：内容图片 ID、必填替代文字（1 至 200）、可选标题（至多 40）与说明（至多 80）、可选链接目标                                                                               |
| `featured` | 推荐位：可选区块标题（至多 20），1 至 6 个文章条目；条目可选替换标题（至多 100）与替换图片（内容图片 ID 与必填替代文字，1 至 200），缺省时使用文章当前上线版本的标题与封面及其替代文字 |
| `columns`  | 栏目入口：可选区块标题（至多 20），1 至 12 个栏目条目；条目可选简介（至多 20）和图标键                                                                                                 |
| `articles` | 文章列表：可选区块标题（至多 20），来源为全站或一个栏目，数量 1 至 12；公开读取时取该来源最新上线的文章，不需要为新文章重新发布首页                                                    |

文字字段沿用[文章](articles.md#身份与内容)的规范化规则。图标键属于随网站发布的固定图标集，不接受上传的 SVG 或图标 URL，以免为图标放宽 CSP 或引入可执行内容。轮播与推荐位图片遵守[内容图片](images.md#上传与处理)的上传上限与用途尺寸规则。

首批链接目标只允许站内文章或栏目，以 ID 引用，不提供站外入口。文章正文的链接同样只允许站内，见[正文结构](articles.md#正文结构)。

## 初始草稿

首页编排没有创建动作。迁移安装 `arrangements` 单例行，初始草稿为零个区块，`revision` 为迁移写入的固定 UUID，最后保存人与保存时间为空，表示尚未保存；数据库要求二者同时为空或同时非空，且非空后不能回到空。管理读取对尚未保存的草稿返回空的最后保存人与时间，首次保存以初始 `revision` 作 expected 值，此后按[共同协议](publication.md#动作与成立条件)办理。初始草稿不满足发布要求，因此首次发布前必须先保存。

## 发布校验

发布和恢复在锁后核对：引用的文章当前已上线，引用的栏目存在且启用，引用的图片可用。不满足时分别返回 `409 article_unavailable`、`409 column_unavailable` 或 `409 image_unavailable`，不生成版本或事件。发布以共享锁锁定被引用的文章和栏目，撤回文章或停用栏目须等待发布提交，二者不会交错出不一致的上线结果。

首页草稿可以引用尚未上线的文章，便于提前编排。首页维护者经首页候选读取选择文章：全部文章按草稿最后保存时间降序、再按 ID 降序分页，每项只含 ID、草稿标题、栏目名称、[状态](articles.md#管理读取)和当前上线标题，不含正文、摘要或办理人。被首页草稿或版本引用的文章和栏目不能删除。

## 上线与回退

首页编排不提供撤回。撤回会让首页回到站点内置内容，而内置内容不随编排更新，容易出现过时信息。需要回退时恢复到某个历史版本，恢复同样执行上节的校验。

已上线首页引用的文章后来被撤回，或引用的栏目后来被停用时，公开解析跳过失效条目。区块没有可展示条目时，整个区块隐藏。管理页保留失效引用的维护提示，不因公开隐藏自动生成新首页版本。

## 公开解析与预览

公开读取在一个只读快照内解析当前上线的首页版本：文章条目附该文章当前上线版本的标题、摘要、封面和地址，栏目条目附栏目名称与 `key`，文章列表区块按[文章排序](articles.md#公开可见性)取最新若干篇。图片以公开图片地址返回。解析结果不含草稿、版本号或办理人。

管理页读取首页草稿时，同一快照内附带被引用文章的当前上线摘要（未上线为空）和图片的短期管理链接，并用与公开页面相同的客户端组件渲染预览。管理页在预览之外保留失效引用的维护提示。预览不经过站点服务端渲染，也不生成公开地址。

## 验收

验证区块类型与字段的封闭集合、数量与长度边界、未知图标键拒绝。覆盖新库的初始草稿可读、以初始 revision 首次保存、空编排发布被拒绝。覆盖引用未上线文章、停用栏目或不可用图片时发布与恢复被拒绝，发布与文章撤回的锁竞争，被引用文章和栏目拒绝删除，首次发布前公开读取返回 `home_unpublished`，文章列表区块随新文章上线变化而无须重新发布。公开解析与管理预览各自在同一快照内完成。首批拒绝站外入口；失效条目被跳过，区块空时隐藏，管理提示保留，且不自动改变首页版本。
