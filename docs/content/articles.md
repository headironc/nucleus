# 网站文章目标设计

首版范围与旧目标的取舍见[网站公开内容](../engineering/delivery.md#网站公开内容)，实际交付状态见[能力台账](../README.md#能力状态)。以下尚未实施的设计须在首个内容消费者实施前按简化架构重新评估，不因内容纳入首版而自动采用全部机制。

本文拥有文章的身份、内容形状、正文约束、发布校验、公开可见性、删除和管理列表。草稿、版本、上线事件及其并发与恢复由[共同协议](publication.md)拥有，栏目见[栏目](columns.md)，图片见[内容图片](images.md)，入口与错误码见[内容 HTTP](http.md)。

## 业务边界

文章由内容维护者在网站管理页编辑，保存草稿与发布是两个动作。文章另有本系统之外的内部审核流程，站内不设发布审核，发布即上线；以后加入审核按[共同协议](publication.md#对象与不变量)扩展。文章不设评论、点赞、收藏或作者账户，参考稿中的计数不属于本能力。投稿不在本片范围：已确认方向是任何正常注册账户都能投稿，这属于本人办理而非角色权限，不为此单设权限领域；稿件经有权者审稿后才进入文章草稿或版本，按[共同协议](publication.md#对象与不变量)的扩展点接入，具体规则另行设计。

## 身份与内容

文章身份行保存服务端 UUIDv4 `id`、创建时间、创建 Operation-Id、首次上线时间和当前上线指针。`id` 同时是公开地址段，不另设可编辑的地址名，这样标题修改和重名都不影响已收录的地址。首次上线时间在第一次发布时写入，之后不变。

草稿与版本使用同一内容形状：

| 字段       | 规则                                                                         |
| ---------- | ---------------------------------------------------------------------------- |
| `columnId` | 必填，引用现存栏目                                                           |
| `title`    | 0 至 100 个 Unicode 标量，NFC 规范化，去首尾空白，不含控制字符；发布要求非空 |
| `summary`  | 0 至 200 个 Unicode 标量，同上规范化；用于列表摘要和搜索引擎描述             |
| `byline`   | 0 至 50 个 Unicode 标量的署名展示文字；不关联人员或账户                      |
| `cover`    | 可空；内容图片 ID 与必填替代文字（1 至 200 个 Unicode 标量）                 |
| `body`     | 结构化正文，约束见下节；发布要求至少一个含文字或图片的块                     |

草稿允许标题和正文为空，便于分次编辑；形状、长度和引用约束在保存时即校验。

## 正文结构

正文保存为带格式版本的项目自定义封闭节点 JSON，结构对齐 ProseMirror 文档的子集。客户端组件按节点渲染，不注入任意 HTML。存储格式与编辑器解耦，网站编辑器约束见[网站组件](../client/website.md#组件)。正文须满足：

- 节点与标记属于带格式版本号的封闭集合。未知节点或属性、内联样式、class、原始 HTML、脚本、iframe 和事件属性一律拒绝。
- 首批节点为段落、二至四级标题、有序与无序列表、引用、分隔线和图片；标记为粗体、斜体和链接。新增节点须先修订本文。
- 图片节点只引用内容图片 ID，并带必填替代文字和可选说明；不接受外部 URL 或 data URI。
- 首批链接只接受站内相对路径，拒绝站外绝对地址和其他 scheme，与[首页链接边界](home.md#区块类型)一致。
- 规范 JSON 不超过 256 KiB，节点不超过 5,000 个，嵌套不超过 8 层（初值）。正文图片数量由[发布校验](#发布校验)限制，图片尺寸由[内容图片](images.md#上传与处理)拥有。

服务端用受控 Rust 类型整体反序列化和校验，并保存同一规范表示。数据库只证明存储合法；读取时仍经同一类型解码，解码失败是完整性故障，不返回部分正文。

## 发布校验

发布在锁后核对正文图片数量。正文至多 100 张，超出返回 `409 article_image_limit_exceeded`，不生成版本或上线事件。此数量上限在发布时校验，草稿仍遵守[正文结构](#正文结构)的其他约束。

发布在锁后核对：栏目存在且启用，否则 `409 column_unavailable`；标题与正文非空，否则 `409 article_incomplete`；封面和正文引用的图片均可用，否则 `409 image_unavailable`。恢复只重查目标版本的栏目仍启用；版本引用的图片受永久保护，不会失效。

## 公开可见性

只有当前上线版本公开。公开结果包含文章 ID、标题、摘要、署名、封面、正文、栏目名称（栏目启用时另附 `key`）、首次上线时间和当前版本上线时间；不返回草稿、版本号或办理人。撤回后公开读取返回 404。站点服务端在其缓存期内仍可能展示旧数据，缓存期由[网站交付](../http/site.md)拥有。

栏目页与全站文章列表只含当前上线的文章，按首次上线时间降序、再按 ID 降序排列，使用[共同分页](../http/lists.md)。恢复和再次发布不改变首次上线时间。站点生成 `sitemap.xml` 不翻页读取这一列表，而用[内容 HTTP](http.md#公开读取) 的专用地址枚举，其中的最后修改时间取当前版本上线时间。

## 删除

只有从未发布（没有任何版本）的文章可以删除。删除共同移除身份行、草稿和草稿图片引用，被释放的图片按[内容图片](images.md#引用与保护)起算宽限，并保存原完成。已有版本的文章不能删除，返回 `409 article_published`，可以撤回。首页草稿或版本仍引用该文章时返回 `409 article_referenced`。

## 管理读取

管理列表包含全部文章，按草稿最后保存时间降序、再按 ID 降序分页，可按栏目和状态筛选。状态由事实推导：`unpublished` 表示没有版本，`published` 表示当前指针非空，`withdrawn` 表示有版本而当前指针为空。每项返回 ID、草稿标题与栏目、状态、当前版本号、草稿最后保存时间，以及草稿是否与当前上线版本不同。单篇读取返回完整草稿、草稿 revision、当前上线摘要和图片的短期管理链接。

## 验收

覆盖正文图片数量的发布边界和超量拒绝，核对拒绝后没有新版本或上线事件。

验证内容各字段的规范化与长度边界、草稿允许空标题而发布拒绝、正文封闭集合拒绝未知节点、样式、HTML 和非法链接 scheme，以及体积、节点数和深度上限。覆盖停用栏目的发布与恢复拒绝、图片不可用拒绝、撤回后公开 404、首次上线时间在恢复后不变、栏目页与全站列表排序和分页、从未发布文章的删除与已发布文章的拒绝、被首页引用时拒绝删除。用固定样例验证版本化 JSON 的服务端规范化与客户端渲染一致。
