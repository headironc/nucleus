## 2. 专题来源

### Turnstile 真实样本边界

2026-10-01 提供的真实验收摘要记录：同一真实 token 换验证 ID 再次提交，仍曾返回成功；约 8 分钟后返回 `invalid-input-response`。该摘要不确定供应商内部的消费或缓存机制，也不证明准确的失效临界点。供应商单次消费保证尚未验证，C1 继续依靠本地 token 占用防止跨原操作复用。

原始响应保留在本地 `/tmp`，未纳入仓库。此次仅依据验收摘要界定结论，未读取原响应；具体文件名、摘要和逐次请求上下文未在此绑定。该材料不构成完整 C1、数据库时间接纳或全部部署设置的验收。当前协议与本地责任见 [Turnstile 人机校验](../platform/turnstile.md)。
