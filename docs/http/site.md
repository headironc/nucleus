# 网站交付与后端边界目标设计

状态：目标设计，尚未实施。网站独立构建和托管，Rust 后端不交付网站页面或构建资源。本文拥有网站托管、后端入口、公开设置与浏览器交付的边界。普通业务 HTTP 的请求头、响应封装及豁免清单由 [HTTP 入口与响应](api.md)拥有。页面和功能范围见[网站与小程序页面](../client/pages.md)。

## 托管与路由归属

网站托管负责 HTML、脚本、样式、构建资源和微信授权完成页。nucleus 负责业务请求、上传和签名文件读取。微信回调、健康检查和 OpenAPI 也由 nucleus 交付。业务事实、权限、事务和恢复仍归后端能力。网站不连接业务数据库，也不承担后台渲染或文件清理。

生产 Nginx 将网站路径交给网站托管，将后端路径转发给 nucleus。代理责任见 [HTTP 接入目标](api.md#nginx-接入与传输目标)。网站与浏览器使用的后端入口保持同一准确 HTTPS origin。独立托管不改变现有 Cookie 与同源要求。微信回调由后端核验证明并处理原操作，再跳转到网站托管的固定完成页。回调与完成页的路径、证明和结果判断见[微信身份](../identity/wechat.md)。

网站托管产品、构建工具及发布方式随网站切片选定。后端仍保持单实例、单应用进程；这一限制不要求网站托管与后端共用进程。网站发布不要求重新编译或重启 nucleus。

## 入口与响应

| 入口                         | 交付者   | 成功响应                                          | 失败与请求标识                                              |
| ---------------------------- | -------- | ------------------------------------------------- | ----------------------------------------------------------- |
| `GET /`                      | 网站托管 | 200；匿名介绍 HTML，不含人员资料                  | 不校验或回显 `Operation-Id`；失败返回 JSON `code`           |
| `GET /app`                   | 网站托管 | 200；匿名应用壳 HTML，未登录时不装入受限资料      | 同上                                                        |
| `GET /assets/{build}/{file}` | 网站托管 | 200；构建清单内的固定字节和准确媒体类型，匿名可读 | 不校验或回显 `Operation-Id`；无匹配资源返回 404             |
| `GET /settings`              | nucleus  | 200；`code: "ok"` 与具名 `settings` 对象          | 普通 JSON 读取，要求有效 `Operation-Id`；响应不回显请求标识 |

`settings` 只含公开的 `challenge.turnstile.siteKey`。nucleus 从已校验的非秘密设置投影该值。响应不包含 AppSecret、凭据或完整应用设置。前端 `build_id` 由网站发布清单拥有，不进入后端设置或该响应。网站构建不嵌入各环境的秘密。小程序只配置自己的公开 AppId 与批准的 HTTPS API origin。

网站托管的静态成功响应直接返回 HTML 或资源字节，不套 JSON。清单内没有对应公开资源时返回 404 `resource_not_found`。非法资源路径返回 400 `invalid_input`；两类失败均返回 JSON、设置 `no-store`，不反射输入路径或操作头。后端保留未知业务路径的 JSON 404；部署入口不得把后端错误改成网站首页。网站内部使用 hash 路由，它不扩大托管端接受的静态路径。

## 构建、发布与缓存

网站构建生成发布清单，固定 `build_id`、资源路径、摘要和媒体类型。发布过程核对清单与实际字节，不一致时拒绝发布。页面与对应资源按同一构建交付，不混用其他版本的字节。托管端只开放清单内的固定资源，不按用户输入拼接任意路径。禁止目录列举和后端私有文件树访问。

nucleus 不嵌入网站构建产物，启动与就绪检查不读取网站发布清单。后端业务依赖、文件挂载和默认业务资源仍按[启动规则](../architecture.md#启动顺序)核验。网站发布和端到端可用性单独验收；后端就绪不证明网站已正确发布。

HTML 与 `GET /settings` 使用 `no-store`。摘要资源可长期以 `immutable` 缓存；私有 JSON 和业务图片按所属用例的缓存协议交付。网站不使用 service worker 或离线业务写入队列。旧页面发现 `build_id` 变化、资源缺失或响应结构不匹配时停止发起新动作并提示重新加载。仍合法的原操作定位按[客户端原操作恢复](../client/recovery.md)保留，页面不自动重放写入。

当前构建标识由网站托管提供，读取路径与版本检查方式随网站切片交付。nucleus 的公开设置接口不维护前端构建标识。前端以固定的后端契约构建，独立发布仍须验证[客户端协议](../client/protocol.md)。

## 浏览器边界

普通应用使用预编译模板和外部脚本，不执行动态模板、`eval` 或任意 HTML 注入，不用 URL 传递会话。CSP 默认仅允许同源脚本、样式、连接和资源；图片按实际预览需要开放 `blob:`。加载人机校验的页面只增补该组件必需的脚本和 frame 来源。对象嵌入、被其他页面嵌套和跨源表单默认拒绝。

微信授权组件及完成页按[微信身份](../identity/wechat.md)的独立浏览器隔离交付，不继承普通应用的人机校验许可。网站托管负责 HTML 响应的 CSP、`X-Content-Type-Options: nosniff` 和 `Referrer-Policy: no-referrer`。构建产物不发布 source map，也不包含测试秘密。网站不把业务资料写入控制台、埋点或错误上报正文；诊断只记录必要的错误码、公开构建标识和受控操作定位。网站托管与部署入口的访问日志沿用后端敏感路由的去值规则。

承载微信授权的父页面只为该组件增补准确的 frame 来源，不执行供应商脚本。若实际组件需要本地网络访问委派，只对已核验的准确来源声明该权限；浏览器或用户拒绝后保留同一授权的扫码办理，不扩大来源、不重发授权或改走新的原操作。真实浏览器、协议替身和真实平台结果分别记录，不能以任一项替代其他项的验收。

## 验收

通过实际部署入口验证网站与后端的路由归属。逐项核对媒体类型、公开字段、缓存头和请求标识边界。覆盖未知业务路径、清单外资源、非法路径、目录列举与私有文件访问。这些请求不得返回首页或文件字节。核对微信回调进入后端，固定完成页由网站交付。后端 OpenAPI 只描述实际后端路由，不收录网站页面。

篡改网站清单或资源字节时拒绝发布。验证网站发布无需重启后端，后端无需网站产物即可启动。用浏览器验证深链 hash 刷新、构建版本变化和资源缺失。匿名壳不得泄露受限资料。分别核对普通应用与微信完成页的 CSP，检查构建产物不含秘密和 source map。网站托管和这些验收尚未交付。
