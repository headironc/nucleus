# 本地文件

本文拥有现有私人文件组件的合同，以及尚未实施的简化工牌文件目标。文件与数据库的先后由[架构](../architecture.md#文件与数据库后果)拥有，备份由[备份与恢复](../operations/backup.md)拥有。已实现的头像上传、更换、读取及文件组件继续遵守迁移前合同。

## 根目录与资源身份

部署提供专用私有目录，启动检查挂载与访问权限。目录缺失时明确失败，不静默改写其他位置。文件名使用服务端生成的 UUID，不用姓名、手机号，不接受客户端路径。读取只定位预期常规文件，不允许路径穿越或通过符号链接读其他文件。

工牌快照保存照片和模板资源 ID；成品 ID 定位[正式成品图片](../workforce/fulfillment.md#成品格式)。固定资源不能同路径覆盖。背景或字体更新使用新标识，旧申请继续引用旧字节。不建立通用资产表或远程对象存储。

## Workforce 封装与换钥

首版工牌采用私有文件、会话与对象权限、加密备份，不新增逐文件密码封装、AAD、文件换钥意图或明文与密文双摘要。已有人员敏感字段的加密继续有效，旧密钥随真实引用保留。

## 发布与正常中断恢复

文件先写完整，再由所属用例保存引用。文件处理失败不保存成功结果；数据库保存失败可留下无引用文件。没有响应时刷新业务状态，成品未形成时人工重试，不按发布意图自动恢复。

每次生成使用独立候选文件名，避免并行或晚到写入覆盖已采用文件。申请状态和成品唯一约束决定采用结果，不以文件存在代替数据库业务状态。

## 现有文件组件合同

以下要求适用于已实现的私人文件组件及头像消费者。工牌可复用其持久写入和读取能力，但不新增发布意图、原工作恢复或资源生命周期框架。组件简化随实际消费者迁移，不只关闭保护或检查。

文件调用者先确认所属意图，并协调同一候选的工作。发布同步文件、分片目录及祖先目录，再返回持久结果；已有同名正式文件必须与本次字节一致，不能覆盖不同内容。重试还须补齐目录同步。文件调用失败不证明发布未发生，由原工作核对并恢复。

文件操作同步执行。调用者负责将阻塞工作纳入监督，并持有许可直到实际结束。读取先在资源协调范围内打开文件，再保留句柄；删除目录项不使已取得的句柄失效。删除只处理调用者指定的私有对象，已不存在的对象视为删除完成；可否删除及重试时机仍由业务所有者决定。

工牌照片使用组件的目录文件锁，将物理文件枚举和发布放在同一互斥范围；容量策略由[照片能力](../workforce/media.md#存储与原结果)拥有。枚举继续通过持有的目录句柄定位，拒绝符号链接、特殊文件、非私人权限或其他设备。统计包含可写的未完成候选，不能只统计可读的正式文件。锁随实际持有的目录句柄关闭而释放；部署和维护不得在写入运行时替换其目录身份。

## 保护与清理

保留申请快照引用的照片、背景与字体，以及已采用成品。取消或人员注销不自动删除这些历史材料。没有业务保留期限前不做按年龄删除。

无引用文件由维护者在停止相关写入的窗口清理，先核对数据库引用与当前目录。提交响应丢失时不能立即删候选，因为数据库可能已经保存引用。不建立 deleting/deleted 状态机或后台清理队列。

## 签名读取

新工牌不使用短期签名链接。每次下载由当前会话、账户状态及本人或管理对象权限鉴权。目录不配置成公开静态资源；UUID 难猜不替代权限。

退出、暂停或失权后按当前权限拒绝后续读取。响应使用适用的私有缓存或 no-store，避免敏感资源进入公共缓存。缺文件明确报错，不解释为“尚未生成”，不返回替代字节。已有头像签名入口不因本设计自动改变。

## 验收

验证路径与权限、非法格式和体积限制、快照资源不可覆盖、他人文件不可读。验证写文件失败无成功引用、数据库失败可留下残留、重复生成不覆盖、缺文件可诊断，以及备份恢复后原文件可用。不要求发布意图、自动接管或逐文件换钥验收。
