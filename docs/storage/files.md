# 本地文件

本文拥有文件身份、可信路径、封装、资源保护和签名格式。数据库保存业务归属与权限，本地持久卷保存不可变字节。共同发布、接纳、删除与换钥由[架构](../architecture.md#文件与数据库后果)拥有。文件设施不拥有业务表或公共资产身份。能力状态以[文档导航](../README.md#能力状态)为准。

## 根目录与资源身份

nucleus 从部署配置取得 `storage.root`，启动时核对预期挂载、同一文件系统、目录和权限；挂载缺失不能退到根文件系统的普通目录继续写。实际设备和位置由部署输入提供，不写死机器路径。私有目录不以姓名、手机号或账户命名，不接收客户端路径、文件名或任意资源类型。每个所有者按自己的 UUID 资源 ID 导出固定相对路径，分片使用规范 UUID 十六进制前四位；临时与正式路径必须同卷。只打开常规文件，不跟随符号链接。

头像用 Avatar ID 定位用户文件，默认头像随应用发布并由摘要清单定位。背景用独立 Background ID 定位，元数据仍在 Template 行；草稿换图更换 Background ID，不改变 Template ID。字体、照片、工牌分别用自身 ID，存于各自私有目录。网站公开内容图片用 Image ID 定位，存于独立私有目录，不加密，读取时核对摘要与大小，规则见[内容图片](../content/images.md#事实)。没有公共文件或资产表、通用资源类型列或文件路径数据库列。即使两类资源碰巧有同样 UUID 字节，目录和加密用途也隔离。注销不改资源 ID、所有者行或路径。

文件元数据由资源所有者保存：明文摘要和大小、适用图片尺寸、加密封装的物理摘要与大小，以及 Workforce 数据密钥版本。摘要恰为 32 字节、大小为正，复合加密列整体及子字段都非空；真实外键只证明业务对象存在，不能证明文件字节存在。共享值类型只封装摘要、大小与可信 Path，不持资源 ID、权限或生命周期。ready 状态缺少物理文件是完整性故障，不解释为正常清理。

## Workforce 封装与换钥

背景、字体、照片和工牌使用 `encryption` 派生用途及 AES-256-GCM-SIV 封装。AAD 绑定域 `nucleus/workforce-file/v1`、所属资源 ID 与固定文件模块标记；同 UUID 的不同资源不能互用密文。先按物理摘要和大小读取完整封装，完整鉴别后再核对明文摘要与大小，不能流式释放未经认证的字节。单份明文最多 32 MiB，读取及计算受有界许可约束。Badge Layout 和 Review、Render、Delivery Confirmation 使用同用途下各自的字段域及记录身份重新封装；增办复制 Layout 或首尝试复制 Confirmation 须先鉴别原值，再按新记录 AAD 封装。注销不改变这些身份或原决定。

文件换钥采用[架构协议](../architecture.md#文件换钥)。所有者的 SQL 意图固定原、新 key ID 和物理元数据，明文身份与业务 ID 保持不变。退役扫描覆盖意图、Layout、Confirmation 和发放输入证明。已确认 deleted 且无工作依赖的资源只保留旧键元数据，不要求不存在文件的旧秘密。

## 发布与正常中断恢复

发布与恢复按[架构](../architecture.md#发布与接纳)执行。每类资源拥有 SQL 发布意图，不在文件系统另建业务恢复清单。候选 ID、正式资源 ID、文件 AAD 与采用结果一致。草稿换背景使用新的 Background ID，意图同时固定旧背景身份；原完成成功后旧背景退出新读取，旧链接不能指向新图。

文件调用者先确认所属意图，并协调同一候选的工作。发布同步文件、分片目录及祖先目录，再返回持久结果；已有同名正式文件必须与本次字节一致，不能覆盖不同内容。重试还须补齐目录同步。文件调用失败不证明发布未发生，由原工作核对并恢复。

文件操作同步执行。调用者负责将阻塞工作纳入监督，并持有许可直到实际结束。读取先在资源协调范围内打开文件，再保留句柄；删除目录项不使已取得的句柄失效。删除只处理调用者指定的私有对象，已不存在的对象视为删除完成；可否删除及重试时机仍由业务所有者决定。

## 保护与清理

活动申请和已生成 Badge 的引用保护照片及模板效果；未明确结束的申请即使注销仍保护材料。任意已形成 Badge 的成品、Layout、所用照片与模板效果永久保护，是否发放无关。模板行，包括草稿，保护其背景及主备字体；当前系统默认字体设置也保护所指 Font。无保护照片由本人明确删除，不按时限自动删除可见内容；注销时将该人员无保护照片纳入所属清理。字体失去最后模板引用后以 `released_at` 起算适用宽限，照片 `released_at` 只记录回到可删除状态，不再起算自动删除期限。旧引用与已注销人员仍参与全部保护检查。

删除顺序由[架构](../architecture.md#删除与读取)规定。deleted 是不可复用终态；历史需要时保留 ID、摘要、尺寸和所有者。没有引用、原完成或工作依赖且字节已清理时才能删除整行。头像采用自己的行删除与 SQL 意图。清理批次初值为最多 128 个候选，单后台数据库槽位；遇到在途、未知或关联矛盾对象时保留。

## 签名读取

业务 JSON 入口在决定性快照内检查当前会话、账户、具体职责和可读对象，只有资源字节 ready 且可用才签发短期链接。图片和字体 GET 只验证该资源的短期签名，不要求 Cookie、Bearer 或 Operation-Id，也不授予业务 JSON 读取或写入权。Workforce 链接使用 `link` 派生用途（HMAC-SHA-256）、域 `nucleus/workforce-image/v1`、规范 GET 路径以及 `key_id`、`expires_at` 查询字段，拒绝重复、未知和非规范参数。默认及最大期限为 10 分钟，可配置更短；达到到期时刻即拒绝，不由 GET 续期。签名密钥在停止签发后仍保留最后可能签发时刻加最大期限，按可信时钟退役。

验签后 resolver 按资源 ID 导出可信 Path，按[读取协议](../architecture.md#删除与读取)锁定资源状态并打开准确文件句柄。退出、暂停、失权或注销后，已签发链接在有效期内仍可读取原字节；新签发重查权限。合法清理、旧背景退出读取或 deleted 时返回 404；ready 缺文件及依赖故障返回 503。签名错误、缺失、过期或跨资源替换统一返回 `403 image_link_invalid`，验签前不读取资源。字节成功返回静态 WebP 或接纳字体媒体类型，带 nosniff 与私有缓存；JSON 签发及图片错误为 no-store。日志和代理不保存完整签名 URL、图片或密钥。

传输候选预算为并发 4、总时限 30 秒；读取解密和发送占同一许可，无许可返回 `429`，不排无界队列。按来源每分钟 60、突发 10，进程总每秒 20、突发 20 的读取桶与其他业务桶独立。容量须用真实部署样本验证。

## 验收

验证挂载缺失拒绝写入、可信路径与不跟随符号链接、密码完整鉴别、资源元数据及明文和物理身份。覆盖签名缺失、过期、跨资源、失权后旧链接、合法清理后的 404 与 ready 缺文件的 503。永久 Badge 引用、注销后的旧路径和无保护照片按业务规则验证。共同发布、删除和换钥的故障注入由[架构验收](../architecture.md#隔离验收)拥有；当前没有完整文件能力运行结论。
