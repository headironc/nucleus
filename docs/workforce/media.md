# 工牌模板、照片与预览目标设计

状态：目标设计，尚未实施。Badge 属于 Workforce；本文拥有模板、背景、字体、照片、客户端预览与正式排版的输入和资源边界。申请、制作与发放分别由后续专题拥有。文件的共同发布、读取和清理协议由存储设计拥有。工牌使用单面版式，具体背景、尺寸、字体与打印样本在模板配置及制作验收时给出。

## 模板与固定资源

具有 `workforce.templates` 的维护者上传一张在系统外制作的背景图，设置单面画布、照片框，以及姓名、编号、科室、职称四个动态文字区域。固定文字、标志和装饰属于背景；不提供任意图层、脚本或绘图程序。模板内容为封闭 `content` JSON：版本、实际物理尺寸、出血和 DPI、照片框及四个文字区域的坐标、大小、字号范围、换行、最大行数、颜色、对齐。结构由受控类型整体校验；数值有限、范围有效，区域须在画布内。未知字段、外部 URL、文件路径、CSS、脚本或用户 SVG 均拒绝。

模板直接拥有背景文件元数据和独立 Background ID，不设通用背景表。字体文件由 `fonts` 独立拥有，模板以非空外键引用主字体及缺字备用字体，可以引用同一个字体对象。新草稿从当前必需的默认字体设置取得备用字体 ID，之后固定；默认设置后来变化不改原草稿或原创建结果。当前默认字体、任一模板引用和成品使用均保护所需字体。只从模板固定的主备两项已核实字体构建字体库，不读取操作系统字体目录，也不联网补字体。

模板草稿可在同一事务整体替换名称、背景、主字体、排版与领取地点选项，保留原备用字体；换图取得新 Background ID，只改文字参数时背景身份不变。首次激活共同冻结背景、内容、地点与两项字体，以后 inactive 也不可原地改写。旧模板可重新成为 active，但不能编辑；从未激活的草稿可以删除，其背景由所属删除工作收尾。一个时点至多一个 active；开放新工牌申请时必须有一个字节可用的 active 模板，不能静默选旧模板。

模板固定摘要覆盖排版配置、Background ID 和背景效果摘要、按主备角色排列的字体身份与摘要、以及按顺序编码的领取地点选项。任一内容变动都改变摘要。领取地点是有顺序、非空、不重复的文字数组，原文字节用于确认与匹配，不做模糊地址归一化。每次申请提交须从实际使用模板中明确选择一个地点；地点不打印在牌面，不参与新办、换证和增办的牌面比较。已固定模板的背景与两项字体保持受保护，不能因某次文字未用备用字体而清理。

## 文字排版

每个文字区域固定最小与最大字号、换行开关及最大行数；关闭换行时最大行数为一。目标搜索精度为 0.25 pt，字号范围 0.25 至 256 pt，最多 32 行；固定字号可令上下界相同。服务端按模板 DPI 换算到画布坐标，从最大字号逐档至最小字号，选首个完整可行方案，不假设候选随字号单调。原文及空白在排版阶段不另行规范化、截断、省略或压缩。

缺字时优先主字体，必要时使用模板备用字体；需要共同塑形的文字组合整体使用能够完整表示它的字体，不拆散组合字符。两者均不能表示原字时明确失败，不显示缺字框或搜索第三字体。换行只在 Unicode 允许断点且完整字素边界发生；同一字号按较少行数、再以前行容纳更多原文确定方案。每行按实际使用字体测量宽高与字形轮廓，定位后必须完整落在区域内。溢出、缺字、字体格式不支持和资源不足分别报告，不互相伪装。具体渲染库及其字形覆盖须在实现时按实际输入验证。

获准的正式渲染保存内部固定 Layout：格式版本、模板固定摘要、四个字段所用字体身份及摘要、字号、原文行范围、基线和有限坐标的字形轮廓。轮廓只允许服务端生成的封闭指令；不能接收客户端 SVG 或截图。Layout 含可还原个人文字的内容，按 `workforce_data` 用途加密。AAD 的域固定为 `nucleus/workforce-layout/v1`，字段用途固定为 `badge.layout`；业务身份按 Badge ID、Person ID、固定 Submission 所用 Template ID 的顺序连接三个 16 字节值，整体作为[单个 AAD 字段](../keys.md#54-封装边界目标设计)编码。读取、技术重加密及增办重封装都从各自固定事实重建此绑定；增办使用新 Badge ID，不复用来源密文。Layout 不进普通日志或公开响应。增办复用来源成品的固定布局，不重新决定断行或字形。模板接纳只校验资源和配置，真实姓名等文字的正式排版在获准渲染时执行。

## 照片与客户端预览

上传只接受完整解码的静态 JPEG、PNG 或 WebP，原字节不超过 8 MiB，边长不超过 4096，像素总量不超过 1600 万。本人先明确选择与模板照片框适配的效果，服务端核对比例和像素，重编码以移除元数据；不自动拉伸、旋转或裁剪。照片固定所属 Person、模板、效果、尺寸、加密文件元数据与上传原字节摘要。效果摘要及 Template ID 决定合法复用，Identity 头像不自动成为候选。已删除照片的历史行可以保留必要元数据和原 ID，但字节状态为 deleted 时不能再次提交或复用。

客户端有权读取固定模板配置、背景和两项字体短期链接、可信实名及编号、可选目录和照片，在本地渲染完整预览。必须加载指定字体并执行相同的主备缺字规则，不能用设备默认字体掩盖缺字；资源缺失或文字溢出时阻止确认。预览不在服务端持久保存，也无服务端创建或读取预览图像的接口。客户端与正式服务端使用相同输入规则，但最终打印只使用服务端成品；具体模板的视觉效果由制作验收确认。

提交携带原授权、实名版本、固定编号版本、实际目录 ID 与打印文本、Photo ID、模板固定摘要及明确确认。服务端在同一决定性快照重读可信内容与当前资格；任何影响确认的变化返回 `409 data_changed`，要求重新预览。科室必填，职务及职称可空；未选职称打印“无”。普通新办或换证按当前目录与编号版本核对，合法增办完整复用来源内容及模板。服务器不能以当前默认科室补齐缺失输入，也不能悄悄替换旧确认文本。

## 存储与原结果

`templates` 保存模板 ID、名称、背景 ID、加密文件元数据及尺寸、主备字体 ID、地点列表、封闭内容、状态、创建时间与原操作。背景 ID 在模板间唯一，背景元数据仅指背景。`fonts` 保存 ID、加密文件元数据、字节状态、创建及释放时间与原操作。`photos` 另存所属 Person、Template、尺寸、字节状态、上传原字节 SHA-256 与原操作。文件摘要均为 32 字节，大小为正；加密元数据中的子字段须由表级约束检查，不能只依靠复合类型声明。人员和模板引用均使用真实外键，照片提供同人组合引用供申请提交。

新资源在完整文件接纳后才以 ready 插入。可清理资源以 ready、deleting、deleted 表达字节状态；正常文件发布、更换、删除及进程中断按所属文件工作恢复，旧背景链接不能因草稿换图指向新背景。原创建、更新和删除按[配置原请求](completions.md)识别；对象行上的 Operation-Id 只辅助核对原上传材料摘要，不能替代完成记录，因为草稿及照片可删除。技术换钥只能按停写存储协议修改封装元数据，不能改变明文身份或业务固定内容。

| 路由                                                                                                   | 办理或读取                                                                     |
| ------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------ |
| `POST /workforce/templates`、`PUT /workforce/templates/{id}`                                           | 有权者创建或按 expected 修改草稿                                               |
| `DELETE /workforce/templates/{id}`                                                                     | 有权者删除从未激活且 expected 匹配的草稿                                       |
| `POST /workforce/templates/{id}/activations`                                                           | 比较当前 active 与目标固定摘要后激活                                           |
| `GET /workforce/templates/current`、`GET /workforce/templates/{id}`                                    | 按当前申请或模板维护权读取固定配置及资源链接；草稿只供模板维护者               |
| `POST /workforce/fonts`                                                                                | 模板维护者上传受限字体文件                                                     |
| `POST /workforce/photos`、`GET /workforce/photos/{id}`                                                 | 本人上传及按当前本人或管理读取权查看照片                                       |
| `DELETE /workforce/photos/{id}`                                                                        | 本人以明文 digest 为 expected 删除无保护照片；受保护返回 `409 photo_protected` |
| `GET /workforce/fonts/{id}`、`GET /workforce/photos/{id}.webp`、`GET /workforce/backgrounds/{id}.webp` | 凭有效短期签名读取准确资源字节                                                 |

无保护照片由本人明确删除，系统不按时限自动删除本人可见照片。注销清理由所属资源工作办理。照片先进入 deleting，再删除字节和保存 deleted；已有永久 Badge 引用的照片始终受保护。不提供管理者删除他人照片的入口。签名链接仅在当前有权 JSON 读取时签发，字节 GET 使用准确资源身份和有效签名。

## 验收

覆盖草稿整体替换、换背景身份、首次激活冻结、唯一 active、旧模板再激活、删除草稿后原请求重放，以及系统默认字体变化不改原备用引用。以运行身份验证背景所有权、两项字体真实引用、文件复合值及地点数组的非空和重复约束。验证主备缺字、组合字素、换行、最大字号搜索、溢出与资源错误分开；用具体中文模板与打印样本验证正式效果。验证照片格式及预算、无自动裁剪、元数据去除、预览资源不足、客户端确认变化、已删照片不可复用和文件中断恢复。当前没有这些执行结果。
