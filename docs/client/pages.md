# 网站与小程序页面目标设计

状态：目标设计，尚未实施。网站提供匿名介绍、本人服务和管理服务；小程序提供匿名介绍与本人服务，网站先交付。两端消费相同的服务端事实与权限，不各建一套人员、授权或工牌业务状态。网站按[独立托管边界](../http/site.md#托管与路由归属)构建和发布；小程序使用原生页面。传输与响应见[客户端协议](protocol.md)，会话与原操作见[小程序会话](session.md)、[网站持久会话](../identity/website.md)和[客户端原操作恢复](recovery.md)。

## 页面范围

| 页面组     | 网站                                                                                     | 小程序                                                                       |
| ---------- | ---------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| 介绍与进入 | 公开简介、登录与注册入口                                                                 | 公开简介、本人登录入口                                                       |
| 账户与认证 | 短信及网站微信登录、正式注册、本人账户、头像、登录方式、退出、换号、注销及更正历史       | 小程序手机号和微信身份、正式注册、本人账户、头像、登录方式及退出；不提供换号 |
| 人员档案   | 本人政治面貌及有权管理者的独立档案页面                                                   | 本人政治面貌页面                                                             |
| 参与与编号 | 本人授权、退出、首次领号和邀请码接纳；管理者的角色、准入、授权、编号及邀请               | 本人授权、退出、领号和邀请接纳                                               |
| 工牌       | 本人照片、完整预览、申请、重提、取消和历史；管理者的模板、目录、审批、成品下载与实际发放 | 本人照片、完整预览、申请、重提、取消和历史                                   |

介绍页只用随应用发布的公开内容，不请求人员、授权或工牌列表。管理页使用所属能力的精确候选和分页入口，不增设无权人员搜索或在客户端拉全库筛选。只装配已交付的能力入口；页面缺失不能被解释为已有授权，菜单显示也不能替代服务端当前权限检查。登录后分别读取当前账户、机构角色、Workforce 授权及领域角色；普通注册不自动显示为已经加入 Workforce。账户暂停停止本人服务；仅领域暂停仍保留合法的本人退出和取消未发放申请入口。

网站首批工牌链从真实注册和合法管理来源开始：直接准入、领号、照片与完整预览、选择领取地点、提交、审批及渲染、制作下载、成功保存发放，再验证增办或换证。管理动作先显示目标、原版本和后果，由人明确确认；切页、重连或后台刷新不自动批准、发号、发放或注销。响应丢失保留原 Operation-Id 和输入并核对，不用新标识猜结果。实际放卡与系统成功发放分别呈现，不提供离线发放或历史补记。

网站发码页面按 [Turnstile 生命周期](../platform/turnstile.md#网站-widget-与-token-生命周期)管理组件和候选证明，按 [C1 证明恢复](recovery.md#c1-证明与-widget-恢复)保留已提交操作。前端显示挑战成功不代表已取得短信发送许可。

## 工牌预览与管理交互

头像与工牌照片分别办理。照片旋转或裁切须先展示效果再确认，不静默改变输入。本人选择当前可用科室，分类默认科室仅用于初次预选；切换科室后清除不再适用的职务，并重新确认。职务与职称可不填；分类配置缺失时显示暂不可办理，不虚构默认值或把目录选择解释成人事任职。目录管理分别处理科室、职务列表和分类默认规则，不改写已有申请。

工牌预览在客户端用固定模板、背景、主备字体和可信业务资料绘制完整单面；缺字使用备用字体，两者均不能表示或加载失败时阻止确认。不能借设备字体、截断、省略号或压扁文字制造成功预览。提交保存本人确认的内容和资源身份，正式排版只在批准后由服务端完成。预览溢出提示具体字段；服务端渲染失败展示原 Render 结论，不改写为驳回。两端遵守同一资源规则，不承诺逐像素完全相同。

申请按本次固定模板展示有效领取地点，地点在画布外并随 Submission 保存；增办可重选本次地点，但牌面和 Layout 仍来自原合法来源。切换模板、编号版本或管理确认时，页面显示原内容与当前资料差异；`409 data_changed` 要求刷新并重新确认，不自动换目标或重放旧键。制作与本人详情显示同次保存的地点，发放入口不再提供另一地址字段。管理确认包含当前编号版本，与申请固定版本分开；适用撤销由服务端判断。

业务图片、字体和工牌使用所属接口签发的短期 href，字节 GET 不带会话凭据或 Operation-Id；令牌不进 URL。链接过期或合法清理后，按当前资格重新取链并最多重试一次，不重新上传或渲染。离页、切换账户或失权时清除页面持有的链接与临时文件，不长期保存完整签名 URL。网站表单提供标签、键盘操作、焦点和字段错误；本人窄屏与管理桌面均需实际验收。

## 验收

以网站和小程序真实页面覆盖匿名只读、各自认证与正式注册、当前权利变化、目标更改、账号切换和晚到响应；网站扫码交接及小程序存储按所属协议验证。验证政治面貌未填不预选、更正权不自动读值、注销后无旧资料展示；本人和管理页面不泄露完整身份证号。完整工牌链覆盖主备字体缺字、地点选择、并行申请、重提、取消、模板切换、当前差异、渲染失败、制作与发放分界及原结果恢复。验证图片签名不跨资源、过期有界取链、旧有效链接和失权后的新签发分开。

分别记录网站浏览器、原生小程序和真机结果；共享协议的 Node 检查不能代替原生运行，文档可访问不能代替国内网络或平台资格。网站发布与后端 OpenAPI 见[网站交付与后端边界](../http/site.md)和 [HTTP 入口](../http/api.md)。当前没有页面、真机或供应商验收结果。
