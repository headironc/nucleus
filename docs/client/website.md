# 网站工程

本文拥有网站工程 `halo` 的技术栈、样式体系、组件选择、测试工具与包管理。交付状态见[能力状态](../README.md#能力状态)，构建和启动命令见 [Halo 使用说明](../../halo/README.md)。托管、路由归属、渲染分工、缓存和 CSP 由[网站交付边界](../http/site.md)拥有；页面范围、状态与设计稿由[网站与小程序页面](pages.md)拥有；接口类型生成与响应校验由[客户端协议](protocol.md)拥有。

## 工程与包管理

网站代码位于仓库的 `halo/` 目录，有独立的 `package.json` 和 `bun.lock`，用 Bun 安装和锁定依赖。根目录的 `package.json` 与 `bun.lock` 继续只服务文档和仓库工具，见[文档维护](../README.md#文档维护)。本文不写依赖版本号；具体版本由实施切片的 lockfile 固定。

| 层次     | 选择                                                         |
| -------- | ------------------------------------------------------------ |
| 运行     | Node 24，由 systemd 管理网站服务                             |
| 框架     | React 19、React Router 8 框架模式（服务端渲染）、Vite 8      |
| 样式     | Tailwind 4                                                   |
| 组件     | Base UI；轮播用 Embla Carousel；图标用 lucide-react          |
| 接口类型 | 按[客户端协议](protocol.md#同一份接口描述)生成类型与响应校验 |
| 测试     | Vitest 与 Playwright                                         |

公开页面与应用页面的渲染分工按[渲染与网站服务](../http/site.md#渲染与网站服务)实施：公开页面由服务端渲染；应用页面的服务端只输出外壳和加载状态，私有数据由浏览器读取。

## 样式

颜色、字体和圆角沿用 `design/assets/tokens.css`，在 Tailwind 的 `@theme` 中引用。阅读宽度与组件布局归网站样式。Logo 和草木图直接作为构建输入，避免另存一份素材。少数复杂装饰样式放进 `@layer components`。样式以外部样式表发布，满足 [CSP](../http/site.md#浏览器边界) 对 `style-src-elem` 的限制。

可以借用 shadcn/ui（Base UI 版）的组件代码作起点，外观改为原型风格。`design/` 下的设计稿继续用纯 HTML/CSS 维护，不引入 Tailwind 或网站依赖。

## 组件

能用现成组件就用。Base UI 是默认组件层，从网站首片开始引入，并通过其 CSP Provider 关闭内联 `<style>` 元素，规则见[浏览器边界](../http/site.md#浏览器边界)。

| 用途     | 组件                                                                                                                                 |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 验证码   | Base UI OTP Field，交互见[登录与注册设计稿](pages.md#网站登录与注册设计稿)                                                           |
| 轮播     | Embla Carousel                                                                                                                       |
| 图标     | lucide-react                                                                                                                         |
| 文章编辑 | Tiptap；正文格式与允许的节点、标记和属性由[文章正文结构](../content/articles.md#正文结构)拥有                                        |
| 人机校验 | 优先评估 `@marsidev/react-turnstile`；不满足 [widget 生命周期](../platform/turnstile.md#网站-widget-与-token-生命周期)时自己写薄封装 |

Tiptap 设置 `injectCSS: false`，关闭默认样式注入。编辑器样式由站点 Tailwind 提供，按[样式](#样式)发布为外部样式表。只启用正文契约允许的编辑能力。

评估 Turnstile 组件时逐项核对：显式渲染并取得 widget ID；更换 Operation-Id 时以新 `cData` 重新配置；本次 HTTP 等待结束后只重置候选状态；离页移除实例；旧实例或旧操作的迟到回调不能覆盖当前输入和原证明。任一项无法保证即改用薄封装。

C1 使用薄封装，实例回调同时绑定操作与代次。`@marsidev/react-turnstile` 的回调更新方式不能独立证明旧实例隔离，因此本片不引入该封装。恢复材料由 C1 办理保存，widget 只拥有候选 token。

C1 的结果组件只呈现结果区；状态判断、文案选择、动作和标题聚焦仍由发码页面拥有。

## 测试

Vitest 覆盖协议校验、恢复状态、会话选择和工牌预览等不依赖浏览器的逻辑。Playwright 在真实浏览器中验证页面、键盘与焦点、多标签页、CSP 生效及整页跳转。各项验收内容仍归所属文档；Vitest 通过不能代替真实浏览器结果，两者也都不能代替原生小程序或真机验收。
