# 小程序会话与本地资料

本文规定小程序如何保管 Bearer 会话、进入本人页面及隔离本地资料。交付状态见[能力状态](../README.md#能力状态)，构建与受控验证见 [Orbit 说明](../../orbit/README.md)。会话的服务端验证与失效条件由[当前身份](../identity/current.md)拥有；网站的浏览器选择由[网站持久会话](../identity/website.md)拥有。

## 会话记录与进入页面

小程序在原生私有 storage 保存会话 token、原 `expiresAt` 和已确认的账户标识。只有登录或注册结果明确交付会话，且小程序成功读取对应的当前本人资料后，才把该账户作为已登录身份展示。无账户的匿名认证按原流程标识保存，不预先写入账户标识；短期证明和原请求材料按[客户端原操作恢复](recovery.md)处理。

启动时先用保存的 Bearer token 验证当前会话，再装入受限业务页面。会话记录缺失、损坏、存储失败或平台不支持时，遮蔽旧的受限内容，要求重新验证或登录。过期时间用于客户端提前停止使用旧记录；实际有效性以服务端当前检查为准。本地记录不能恢复已撤销或已暂停账户的会话，也不能把账户标识当作登录证明。

小程序为当前会话选择维护本地代次。登录、退出或切换账户时推进代次；异步响应只有在代次和账户仍匹配时才更新页面。从后台返回的 `onShow` 先复核当前会话，再读取受限资料。业务请求仍由服务端逐次核验身份和当前权限。可信的当前会话无效结果显示“请重新登录后继续”，并提供登录入口。HTTP 403 按所属应用码说明本次业务拒绝，不统一显示为登录失效，也不凭页面状态替服务端判定账户或领域资格。原操作证明的错误仍按[恢复结果](recovery.md#读取与响应处理)解释，不作为当前会话失效的依据。

退出及切换账户的确认窗口也绑定打开时的原会话与本地代次。窗口迟到、页面已隐藏或选择已改变时，旧确认不能作用于后来账户。个人账户未显示前不提供这些确认入口。

## 本地资料与清理

客户端不持久缓存业务列表和管理对象资料。图片只按所属接口的权限、缓存指令和有效期限缓存；已有图片字节不证明当前仍有读取或办理权限。匿名认证与注册的原输入仅在[原操作恢复](recovery.md)规定的短期窗口保留，不进入个人资料缓存或表单历史。头像的当前选择和图片缓存另见[账户头像](../identity/avatar.md#链接与缓存)。

退出、失权或切换账户时清除当前页面持有的受限资料和旧会话的可用状态。仍可合法读取的原完成证明按所属恢复期限保留，并隔离于其他账户；不能把退出解释为原写入已回滚。首次发送前保存失败时停止该次写入，显示“设备暂时无法保存办理信息，本次操作尚未发送”。已经发送的操作按[结果恢复](recovery.md)说明当前可确认的情况，不把本地存储失败解释为服务端没有执行。

原材料的到期清理归应用前台寿命，不依赖本人页仍可见。公开首页和其他页面只检查本地截止，不自动请求私有资料或原业务；进入后台停止本地计时，回到前台先清理再使用材料。会话期限超过宿主单次计时范围时分段唤醒重算，不把计时溢出当作会话到期。存储损坏或不可用时先遮蔽资料，提供重新检查；用户明确移除无法使用的本地信息后，才重新验证手机号，仍不改写此前办理的未知结果。

## 验收

验证登录、注册和无账户分流分别保存正确的本地身份；启动、`onShow`、退出和账户切换不显示旧账户资料。覆盖 storage 不可用、记录损坏、token 过期、服务端撤销、账户暂停及倒序响应。401 与 403 显示不同后果，晚到响应不能覆盖较新会话。检查本地持久记录不含业务列表、管理对象资料或超出原恢复期的认证输入。
