# 密钥维护目标设计

状态：目标设计，尚未实施。本文规定根密钥版本与数据库元数据的换钥、技术重新加密、重新封印、提交未知核对及旧根退役。根材料、派生用途和指纹见[密钥材料](../keys.md)，数据库身份与结构交付见[数据库](../database.md)。号码查找编码由[号码查找摘要](../identity/lookup.md)拥有，原请求与微信 code 摘要由[原输入证明](../identity/proofs.md)拥有。各能力的持久引用见[密钥引用范围](key-scope.md)。

轮换只新增一个根版本并把它设为活动根，全部派生用途随之一起切换，不能单独轮换某个用途。

## 停写与提交

维护前准备并验证同时含有必需旧根和新根的候选材料。部署调用方停止新业务接纳，等待全部相关执行结束，并证明旧应用进程不能再提交。维护者以既有部署身份连接，不增加登录身份，也不使用应用进程内的准入队列。

维护事务取得与在线运行共享屏障对应的事务级独占锁，然后核对数据库当前密钥元数据。号码与邀请码查找值按[现行编码](../identity/lookup.md)以新根的 `lookup` 用途重算全部保留记录和当前占用；受保护字段按各所有者的信封与 AAD 规则以新根的 `encryption` 用途技术重新加密；带封印的事实按[事实封印](../architecture.md#事实封印)的退役方式先以原根完整核验，再以新根的 `seal` 用途重新封印。一个事务完成所需重算、唯一性检查、引用核验和活动键元数据切换，不提交部分转换。技术转换保持业务明文、归属、原办理、计数与时点，不创建实名新版本，也不重置会话或注册证明。

维护事务的初始预算为 300 秒，不放宽在线业务的数据库预算。超时或连接断开不能证明回滚。先停止发送新命令并结束原数据库驱动；驱动结束不单独证明后端已结束。新连接取得同一独占锁后，用新的 `READ COMMITTED` 语句读取密钥元数据及相关数据，核对原事务结局。首次初始化的已交付边界见[部署工具](../engineering/deployment.md#密钥初始化与核验)。结局未能证明前，保持停写并报告故障。

确认数据库提交后，才切换服务使用的材料并按[单进程启动与就绪](../architecture.md#启动后台与停止)完成启动核验。材料切换须保留可恢复的先前状态。数据库仍为旧元数据时使用匹配的旧材料；数据库已切为新元数据时使用包含相应新键及仍需旧键的材料。材料与元数据不匹配时拒绝就绪，不能尝试猜测哪组密钥可解密。部署调用方分别核对数据库提交和材料切换的结果。

## 保留与退役

C1 token 摘要采用 `lookup` 用途，其编码与版本核对见[原 token 证明](../identity/proofs.md#c1-原-token-证明)。原 token 不持久保存，换钥保留旧摘要及其根版本，直至 Challenge 的占用和原结果证明依赖结束。新占用仍检查全部保留版本。当前已交付根材料装载、派生、证明计算和初始元数据；数据库换钥及退役核验尚未实施。

技术重新加密只改变相应密文，保持其他证明和查找摘要；注册 token 的原 SHA-256 证明不因重新封装而改变。输入、验证码和微信 code 的旧 HMAC 派生键在仍有原记录需要比较时保留，即其根版本保留。微信 code 不保存明文，不能通过换钥全量重算旧占用；新占用按所有保留版本查询，同一 code 不得再次交换。密钥元数据不按短期请求的期限清理；保留 key ID 也不意味着秘密材料永远保留。

旧根只有在每个用途对它的依赖都结束后才能退役。AEAD 字段与封印能用当前明文在维护事务内转换，查找摘要能按明文重算；无法用当前明文重算的派生用途须等各自的保留期过去：C1 token 与微信 code 占用不保存原文，继续按全部保留版本查询，直至相关短期记录到期；尚未到期的验证码证明（`proof`）需要旧根核对；已签发的头像链接（`link`）停止签发后，至少保留到最后可能签发时点加允许的最长 24 小时，可信时间达到 `retire_after` 才能退役。启动拒绝仍被引用的根缺失，所以旧根要保留到最后一类引用到期。各用途的实际引用和期限由其所有者证明，不能仅按材料年龄删除。

`proof` 仍被 Workforce 授权、领域更换与工号等永久原证明消费。这些证明没有可重算的原输入副本，相关旧根不能沿认证短期保留期限退役。机构在线与停机指派已将规范输入封装在永久[完成记录](../architecture.md#完成记录)中，初始化保存自身完成。未来换钥可以转换这些输入信封及封印，再核对其他用途的引用是否结束。它们不再因缺少原输入而永久依赖旧 `proof` 根。实际引用及启动边界见[密钥引用范围](key-scope.md#启动与交付)；本维护工具仍未交付。

普通重启不统一作废会话、注册证明或次数。已有秘密按原截止释放，窗口内的控制记录继续参与判断。首次初始化入口见[部署工具](../engineering/deployment.md)，不承担轮换或退役。本文只处理正常事务与配置维护中断；运行预算和全量核验耗时仍须实测。

## 验收

用真实数据库事务验证停止接纳、旧进程退出证明、独占锁、全量转换及唯一性检查。覆盖事务回滚、提交回包丢失、材料切换中断、旧材料启动、新材料启动和元数据不匹配。核验原会话、证明期限、请求身份、计数及业务历史均未因维护改变。分别证明每个用途对旧根的退役条件；用不同版本的微信 code 占用验证不会重复外呼。记录实测耗时与预算余量。
