# 政治面貌固定值

本文拥有中心人员档案的政治面貌代码与显示名称。封闭代码供填写、读取、存储解码和 OpenAPI 共同使用。填写、读取、更正和历史归属见[人员政治面貌](affiliation.md)。

政治面貌是单选值，采用 GB/T 4762-1984 的固定代码。项目按以下代码与名称解释已有及新写入的取值，不开放自由文本、多选或可编辑目录。代码是恰好两位 ASCII 数字；名称只用于展示，不作为写入输入。后续标准修订不自动改变已固定的项目值域。

| 代码 | 显示名称       |
| ---- | -------------- |
| 01   | 中共党员       |
| 02   | 中共预备党员   |
| 03   | 共青团员       |
| 04   | 民革会员       |
| 05   | 民盟盟员       |
| 06   | 民建会员       |
| 07   | 民进会员       |
| 08   | 农工党党员     |
| 09   | 致公党党员     |

“未填写”表示该人员没有取值事实，不是第十四个选项，不默认映射为“群众”。输入缺失、`null`、空字符串、非字符串或表外代码均不是合法取值。解密后的历史值也使用同一封闭值域解释；未知代码是数据完整性故障，不显示为自由文本。

## 固定名称读取

`GET/HEAD /api/v1/affiliations` 供本人首次填写和已有值展示使用。当前合法网站会话即可读取。读取不要求机构档案权限或 Workforce 资格。接口不读取任何人的政治面貌。会话与当前账户在同一只读快照内重新鉴别。

成功为 `200`，返回 `{ "code": "ok", "affiliations": [{ "value": "01", "name": "中共党员" }, ...] }`。数组完整返回上表 13 项，按 `01` 至 `13` 排序。`value` 保留两位 ASCII 数字及前导零；没有分页、默认项或“未填写”选项。

入口要求 Operation-Id，沿用[本人读取的同源条件](../identity/current.md#凭据选择与来源)和[元数据预算](../http/admission.md)。不接受查询参数或正文：额外查询或非空正文为 `400 invalid_input`，正文超过 8 KiB 为 `413 invalid_input`。HEAD 使用相同资格和状态，响应无正文。响应禁止缓存，不改变 Cookie、会话期限或持久业务事实，也不登记读取操作。会话、输入及依赖错误沿[共同 HTTP 协议](../http/api.md)。

国家标准平台确认[标准编号与名称](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=70D7C663523807D5EB37A03E97BCCB7B)。[深圳市市场监督管理局公开的 SZDB/Z 159.2—2015 附录 A 表 A.5](https://amr.sz.gov.cn/attachment/1/1191/1191615/9772235.pdf#page=91) 列出上述对应关系，并标明采用 GB/T 4762-1984 的代码。该公开附录是本表名称和代码的核对来源；本次未将国家标准原文全文作为已经核验的材料。

验收覆盖 13 项代码的准确往返和显示、前导零保留、表外代码拒绝，以及“未填写”与“群众”不同。程序内只维护一份封闭映射，HTTP、存储解码和展示共用其受控值。
